1. Who we are

This policy covers the website samvadtech.github.io and the application "Samvad Tech Uploader", a private tool operated by Samvad Tech ("we", "us"). The application is used only by the Samvad Tech team to publish our own videos to our own YouTube channel (@SamvadTech) and our own Facebook Page.

2. What the application does

Samvad Tech Uploader uses the YouTube Data API (YouTube API Services) to upload videos, titles, descriptions, tags, thumbnails and publish times to the Samvad Tech YouTube channel, and the Meta Graph API to publish videos and Reels to the Samvad Tech Facebook Page. It does not access any other user's account.

3. Information we access

  • Google / YouTube: with the permission youtube.upload, the application can upload videos to the channel of the Google account that signs in. It does not read your emails, contacts, watch history, comments, subscribers or any other personal data.
  • Facebook: a Page access token for the Samvad Tech Page, used only to publish our own videos to that Page.
  • Website visitors: this website does not use cookies, analytics, advertising trackers or forms, and does not collect personal information. The hosting provider (GitHub Pages) may keep standard technical server logs, as described in GitHub's own privacy statement.

4. How information is stored

The sign-in tokens created by Google and Facebook are stored only on our own computer, in a private local folder. They are not sent to any server of ours, not shared with third parties, and not used for advertising. Uploaded videos are stored and shown by YouTube and Facebook under their own terms.

5. Sharing of information

We do not sell, rent, trade or share any personal information. Data obtained through Google APIs is used only to provide the upload function described above.

6. Google API Services and YouTube

Samvad Tech Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

The application uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Please also see the Google Privacy Policy.

7. How to revoke access

Access given to Samvad Tech Uploader can be removed at any time from the Google security settings page: https://security.google.com/settings/security/permissions. Facebook access can be removed from Facebook Settings → Business integrations. When access is revoked, the locally stored token stops working and is deleted by us.

8. Data deletion

To request deletion of any information related to the application, contact us at the email below. Locally stored tokens are deleted within 7 days of a request or of access being revoked.

9. Children

The application is not directed to children and does not knowingly collect information from anyone.
